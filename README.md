# 🚢 Titanic Survival Analysis

## 📌 Project Overview

This project explores the Titanic dataset to understand why some passengers survived while others did not.

---

## 🎯 Objectives

* Analyze survival patterns
* Identify key factors influencing survival
* Answer real-world data questions

---

## 📊 Dataset

The dataset contains information about 1309 passengers:

* Age
* Sex
* Passenger class (Pclass)
* Fare
* Embarkation port
* Family relations

Target:

* Survived (0 = died, 1 = survived)

---

## 🔍 Data Analysis

### Key Questions

* Which gender had the highest survival rate?
* Did children have higher survival chances?
* Does passenger class affect survival?
* Does embarkation port influence survival?

---

## 🧹 Data Preparation

* Filled missing values in "Survived"
* Handled missing age values
* Created new features:

  * `Adult` (True/False)
  * `Category` (Man, Woman, Boy, Girl)

---

## 📈 Key Findings

* Women had significantly higher survival rates than men
* Children had better survival chances
* First-class passengers survived more than others
* Passengers from Cherbourg had higher survival rates

---

## 🧠 Insights

Survival was strongly influenced by:

* Gender
* Age
* Socio-economic status (class)
